# Skyline Drop repository guide

- Editable game source is `src/`, with assets in `public/` and the contract in `sfhs.project.json`.
- `dist/index.html` is generated by SFHS. Never edit it directly or commit it.
- The pinned SFHS toolchain is recorded in `one-shot/SFHS-PIN.json`; use a clean checkout of that exact commit for build and verification.
- Preserve the one-way runtime boundary: input -> semantic actions -> simulation -> render. Rendering must not change simulation or save state.
- `historical/candidate/` is retained evidence only; it can never be released as the canonical artifact.
- Keep current and immediately previous canonical evidence. Do not claim physical-device acceptance without an artifact-bound device record.
